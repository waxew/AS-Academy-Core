# راهنمای Model Layer در AS Academy Core

## هدف
Model Layer ساختارهای داده مشترک بین بخش‌های Core را تعریف می‌کند.

## مسئولیت‌ها
- تعریف Entity ها
- انتقال داده بین لایه‌ها
- حفظ قرارداد داده

## قوانین
Model نباید شامل:
- منطق UI
- منطق ذخیره سازی مستقیم
- وابستگی به App خاص
باشد.

## جایگاه
Database / Repository / Engine از Model های استاندارد استفاده می‌کنند.
