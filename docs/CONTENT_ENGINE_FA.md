# راهنمای Content Engine در AS Academy Core

## هدف
این بخش مسئول مدیریت منطق مرتبط با محتوای آموزشی در لایه Core است.

## مسئولیت‌ها
- تعریف قرارداد دسترسی به محتوای آموزشی
- اعتبارسنجی ساختار محتوا
- آماده‌سازی داده برای مصرف لایه‌های بالاتر

## قوانین معماری
Content Engine نباید:
- به UI وابسته باشد
- منطق نمایش داشته باشد
- به یک اپ خاص وابسته شود

## جریان داده
Content Source -> Core Content Engine -> MainCourse -> Application
