# معماری AS Academy Core

## معرفی

این سند معماری داخلی ماژول Core در اکوسیستم AS Academy را توضیح می‌دهد.

Core لایه زیرساختی مشترک تمام برنامه‌های AS Academy است و نباید به هیچ Application خاصی وابسته باشد.

## مسئولیت Core

Core مسئول موارد زیر است:

- مدیریت Runtime
- مدیریت داده و Persistence
- مدیریت Repository ها
- مدیریت محتوای آموزشی
- اعتبارسنجی نسخه‌ها و Update
- ارائه سرویس‌های مشترک به MainUi و Applicationها

## معماری لایه‌ای

```
Application
     |
     v
MainUi
     |
     v
Core Runtime
     |
     +---- Repository
     |
     +---- Database
     |
     +---- Content Engine
     |
     +---- Update Engine
```

## قوانین معماری

- Core نباید شامل کد UI باشد.
- Core نباید به App خاصی وابسته باشد.
- منطق آموزشی باید از طریق قراردادهای مشخص مدیریت شود.
- تغییرات Core باید با توجه به تمام مصرف‌کنندگان بررسی شود.

## استاندارد توسعه

تمام کلاس‌ها و APIهای عمومی باید دارای توضیح فارسی مهندسی باشند تا توسعه‌دهندگان آینده بتوانند تصمیمات معماری را درک کنند.
